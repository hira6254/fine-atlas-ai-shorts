# 株式会社ファインアトラス｜AIショート動画 毎日配信計画 実行コンパス＆365日制作スタジオ

社長計画書（全13章）とファインアトラス実態データ（主力5品目＋拡張5品目・歩留まり85〜99%・飲食店1皿原価率26.5〜30.2%・急速冷凍ドリップ検証データ）を完全融合した、広報担当者1名・1日20〜30分で日英2本（年間730本／4大SNS延べ2,920投稿）を継続配信するための制作スタジオ＆マスター台帳リポジトリです。

## ブランド統一キャッチコピー（全動画 27〜30秒固定）
- **日本語版**：「**日本の旬と品質を、一箱に。世界の厨房へ。**」
- **英語版**："**Japan's seasonal catch & peak quality, in one box. To kitchens worldwide.**"

## 集客から販売までの7ステップ導線（第1章・第11章）
1. **ショート動画毎日配信**（TikTok / Instagramリール / YouTubeショート / Facebookリール）
2. **ファインアトラス認知**
3. **魚の専門情報で信頼構築**（旬・市場相場・急速冷凍科学・歩留まり原価改善・調理法）
4. **ホームページ・Amazonへ誘導**
5. **少量購入で品質確認**（自店の厨房で身質・ドリップ・歩留まりを実地確認）
6. **リピート購入**
7. **法人契約・店舗別オリジナル魚BOXの受注**

## リポジトリ構成
- `index.html` / `styles.css` / `app.js`：AIショート動画 365日制作スタジオ Webアプリ（Vrew字幕・Dot10項目プロンプト・Metricool投稿文ワンクリック出力）
- `data.js`：初回28日間（日英56本）完全10項目台本、365日配信カレンダー（重複ゼロ）、写真350枚＋動画110本（計460点）素材DB、魚種10品目原価マスタ
- `ファインアトラス_AIショート動画_毎日配信マスター台帳.xlsx`：6シート構成のExcelマスター台帳（数式自動集計・ステータスプルダウン付き）
- `docs/社長計画書_ファインアトラス実態融合_実行設計書＆広報マニュアル.md`：全13章完全準拠の実行設計書・広報運用マニュアル
- `scripts/build_deliverables.py`：`data.js` および Excelマスター台帳の一括再生成スクリプト
- `scripts/validate_gate.py`：0.5秒未満で全要件を検証する決定論ゲートスクリプト

## 再生成＆検証コマンド
```bash
python3 scripts/build_deliverables.py
python3 scripts/validate_gate.py
```
